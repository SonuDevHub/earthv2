# Image and Media Credits

All 89 photographic, badge, and citation certificate assets used across the Earth Day Network India static site are documented below. All photographic and badge assets are open-source, Creative Commons, Public Domain, or custom-generated brand graphics. Each item acts as a placeholder until the official client assets from Google Drive are delivered.

**To replace an asset:** Drop the replacement photo into _src/img/ under the corresponding filename (minimum 1800px wide for heroes, 800px for cards/tiles), and run python _src/build.py. Grouped multi-resolution WebP, AVIF, and JPG assets are compiled automatically into ssets/img/<group>/.
